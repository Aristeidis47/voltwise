# VoltWise — HW1 mobile mockup

React + TypeScript + Vite, mobile-first. **Εκπαιδευτικό demo με φανταστικούς παρόχους, τιμές και όρους. Δεν είναι πραγματικές προσφορές.**

## Εκτέλεση του VoltWise από τον πηγαίο κώδικα

**1. Προετοιμάστε τον υπολογιστή.** Χρειάζεστε Git, Node.js **24.22.0 ή νεότερο** με npm, και pnpm **11.25.0**. Στα Windows ανοίξτε τη Γραμμή εντολών (**CMD**). Εκτελέστε κάθε γραμμή ξεχωριστά.

```cmd
git --version
node --version
npm --version
```

- Αν το CMD δεν αναγνωρίζει το `git`, εγκαταστήστε το [Git για Windows](https://git-scm.com/downloads/win).
- Αν δεν αναγνωρίζει το `node` ή το `npm`, ή αν το Node.js είναι παλαιότερο από 24.22.0, κατεβάστε τον **Windows Installer (.msi)** από την [επίσημη σελίδα του Node.js](https://nodejs.org/en/download). Εκτελέστε τον installer με τις προεπιλεγμένες επιλογές για npm και PATH.
- Μετά την εγκατάσταση κλείστε το CMD, ανοίξτε **νέο CMD** και επαναλάβετε τις τρεις εντολές. Συνεχίστε όταν και οι τρεις εμφανίσουν αριθμούς έκδοσης.

Ελέγξτε το pnpm:

```cmd
pnpm --version
```

Αν η εντολή δεν αναγνωρίζεται ή εμφανίζει έκδοση διαφορετική από `11.25.0`, εγκαταστήστε την έκδοση του project και επιβεβαιώστε ότι εμφανίζεται `11.25.0`:

```cmd
npm install --global pnpm@11.25.0
pnpm --version
```

**2. Κατεβάστε τον κώδικα από το GitHub.** Από τον φάκελο όπου θέλετε να αποθηκεύσετε το project, εκτελέστε:

```sh
git clone https://github.com/Aristeidis47/voltwise.git
cd voltwise
```

**3. Εγκαταστήστε τις εξαρτήσεις και ξεκινήστε την εφαρμογή.** Μέσα στον φάκελο `voltwise`, όπου βρίσκεται το `package.json`, εκτελέστε:

```sh
pnpm install --frozen-lockfile
pnpm dev
```

**4. Ανοίξτε την εφαρμογή στον browser.** Χρησιμοποιήστε τη διεύθυνση που εμφανίζει το terminal δίπλα στο **Local**, συνήθως `http://127.0.0.1:5173`. Πατήστε **«Ας ξεκινήσουμε»** για να δοκιμάσετε το mockup. Κρατήστε το terminal ανοιχτό όσο χρησιμοποιείτε την εφαρμογή.

Για τερματισμό, πατήστε **Ctrl+C**. Για να την ανοίξετε ξανά, αρκεί να εκτελέσετε `pnpm dev` μέσα στον φάκελο `voltwise`.

**Προαιρετικός έλεγχος του κώδικα.** Η εντολή `pnpm test` εκτελεί τις αυτοματοποιημένες δοκιμές και η `pnpm run build` δημιουργεί την έκδοση παραγωγής.

## Περιγραφή

Έχουν υλοποιηθεί ο υπολογιστικός πυρήνας, η αρχική φόρμα, τα αποτελέσματα, οι λεπτομέρειες, η σύγκριση δύο επιλογών και το διαδραστικό «Τι αλλάζει αν…». Η Δοκιμή μεταβάλλει kWh/κατανομή/όρους, ενημερώνει αμέσως ποσά και κατάταξη, εξηγεί αλλαγές νικητή και υποστηρίζει μαθηματικές τομές/έλεγχο εύρους. Η αρχική σύγκριση παραμένει ανεξάρτητη. Πριν από οποιαδήποτε επόμενη εργασία διαβάζουμε ξανά PROJECT_SPEC.md, DATA_MODEL.md και RECOMMENDATION_RULES.md.

Ολοκληρώθηκαν και οι δύο προαιρετικές διαδρομές. Στο «Έχω συμβόλαιο» μπορεί να οριστεί ακριβές demo πρόγραμμα για ορατή σύγκριση «Σήμερα / εναλλακτική», με ξεχωριστό γνωστό ή άγνωστο τέλος αποχώρησης. Παράλειψη και «μόνο εταιρεία» δεν δημιουργούν προσωπική χρηματική διαφορά. Το «Δες με δείγμα λογαριασμού» δείχνει ένα τοπικό φανταστικό δείγμα, προσυμπληρώνει 360+240 kWh / 60 ημέρες μόνο μετά από επιλογή χρήσης και απαιτεί επιβεβαίωση. Η βασική ροή παραμένει πλήρης χωρίς καμία από τις δύο επιλογές.

Το domain δεν εισάγει React, DOM, state εφαρμογής ή demo fixtures. Η recommend δέχεται ρητά τον κατάλογο. Η recommendNormalized προορίζεται για ήδη επικυρωμένες καταστάσεις από normalizeConsumption/applyTrial· δεν αποτελεί parser αυθαίρετων εξωτερικών δεδομένων.

Οι μοναδικές runtime εξαρτήσεις είναι react και react-dom. Vite, το επίσημο React plugin, TypeScript και οι τύποι είναι εργαλεία ανάπτυξης. Τα tests χρησιμοποιούν το ενσωματωμένο node:test, χωρίς Vitest, router, state manager ή UI framework. Το pnpm-workspace.yaml κρατά το package store τοπικό στο έργο και το .gitignore εξαιρεί cache, node_modules και dist.

Ελέγχθηκαν focus/πληκτρολόγιο και απουσία file input.
- Δεν καταγράφηκαν JavaScript exceptions, console errors, αποτυχημένα αιτήματα ή εξωτερικές κλήσεις. Δεν παρατηρήθηκε οριζόντια υπερχείλιση στις 28 ελεγχθείσες διαδρομές. Στιγμιότυπα και reports γράφονται στο artifacts/onboarding, artifacts/results, artifacts/whatif και artifacts/optional, που εξαιρούνται από το repository. Έγινε και οπτική επιθεώρηση στιγμιοτύπων.

Ο έλεγχος browser αξιοποίησε το ήδη εγκατεστημένο Playwright του περιβάλλοντος και ιδιωτικό headless Chrome, χωρίς νέα εξάρτηση. Εκτέλεση με `node scripts/check-onboarding.mjs`, `node scripts/check-results.mjs`, `node scripts/check-whatif.mjs` και `node scripts/check-optional.mjs`, αφού ξεκινήσει production preview στο 127.0.0.1:4174. Η μεταβλητή VOLTWISE_PLAYWRIGHT_MODULE δείχνει στο υπάρχον playwright/index.mjs και η προαιρετική VOLTWISE_CHROME_PATH στο εκτελέσιμο Chrome. Η VOLTWISE_SMOKE_URL αλλάζει το τοπικό URL. Τα συνήθη build/unit tests δεν απαιτούν Playwright. Ο αυτοματοποιημένος έλεγχος δεν υποκαθιστά δοκιμή κατανόησης με νέους χρήστες ή πλήρη πιστοποίηση προσβασιμότητας.

Στη φόρμα, το μηδέν είναι έγκυρη κατανάλωση αλλά όχι έγκυρη διάρκεια. Χρήση πάνω από τα συμφωνημένα όρια του demo απορρίπτεται χωρίς περικοπή. Από 1.500 kWh/30 ημέρες εμφανίζεται μόνο υπενθύμιση ελέγχου μονάδας/ένδειξης μετρητή, χωρίς επιπλέον αποκλεισμό ή ισχυρισμό ότι η πραγματική οικιακή χρήση είναι λανθασμένη. Καμία προτεραιότητα, έκπτωση ή κατανομή δεν προεπιλέγεται. Η μηνιαία αναφορά ορίζεται ρητά ως 30 ημέρες και μπορεί να διορθωθεί αλλάζοντας τα αρχικά στοιχεία.

## Ανασκόπηση σε κινητό και desktop

Η ανασκόπηση πρόσθεσε 18 πραγματικές περιπτώσεις σε 320, 390 και 1440 CSS px, πέρα από τις 28 προηγούμενες mobile διαδρομές: συνολικά **46 περιπτώσεις browser**. Στις δώδεκα βασικές περιπτώσεις (4 σενάρια × 3 πλάτη) ελέγχθηκε κάθε υπολογίσιμο πρόγραμμα σε σύγκριση και λεπτομέρειες, κάθε εμφανιζόμενη κάρτα και ολόκληρη η κατάταξη, με τον κοινό πυρήνα και ανεξάρτητα αναμενόμενα ποσά. Ελέγχθηκαν επιπλέον ελλιπής διζωνική κατανομή, ακύρωση/νέα υποβολή χωρίς απώλεια Δοκιμής, στρογγυλοποιημένα όρια, σημειακό εύρος, προσβάσιμα σφάλματα, συγχώνευση ανακοινώσεων, εστίαση χωρίς επικάλυψη, skip link και αντίθεση κύριου κουμπιού. Reports/screenshots: artifacts/review. Εκτέλεση: `node --experimental-strip-types scripts/check-review.mjs`, με τις ίδιες μεταβλητές Playwright/Chrome και production preview που περιγράφονται παραπάνω.

## Όρια και εκκρεμότητες

- Η λειτουργική ανασκόπηση ολοκληρώθηκε με διορθώσεις και τελικούς ελέγχους. Τα προαιρετικά διαγράμματα δεν υλοποιήθηκαν. Εκκρεμεί πραγματική αξιολόγηση κατανόησης με νέο χρήστη.
- Τα πέντε demo προϊόντα κρατούν το ρητά γνωστό μηδενικό τέλος τους. Η φόρμα επιτρέπει και δήλωση άγνωστης εφαρμογής του τέλους, χωρίς να κατασκευάζει ποσό. Η παρουσίαση γνωστού θετικού ποσού ελέγχεται με ακριβές συνθετικό συμβόλαιο 60 €, χωρίς αλλαγή καταλόγου ή φόρμα πραγματικών τιμών. Δεν υπολογίζεται συμψηφισμός/απόσβεση. Έλλειψη κατανομής μπορεί να αποκλείει μηνιαίο baseline, ενώ οι επαληθευμένοι συμβατικοί όροι επιτρέπουν χωριστή εμφάνιση ρήτρας· άγνωστη έκδοση δεν δανείζεται γνωστό μηδέν.
- Υποστηρίζεται μόνο LINEAR_V1 με σταθερό πάγιο και ενεργές γραμμικές τιμές. Κλιμακωτές χρεώσεις ή νέοι όροι εξαρτώμενοι από ποσότητα χρειάζονται νέο μοντέλο/κανόνες· σήμερα απορρίπτονται, χωρίς πλασματικό κόστος ή σημείο ισοφάρισης. Το μεταδεδομένο μοντέλου δεν αλλάζει τον τιμολογιακό DEMO-1. Το slider χρησιμοποιεί αριθμούς μόνο για χειρισμό· ο υπολογιστικός πυρήνας συνεχίζει με ακριβή κλάσματα.
- Παραμένουν η επιβεβαίωση προσωπικού πλαισίου χρήσης, η αξιολόγηση επάρκειας διαφοροποίησης και τυχόν πρόσθετος ορισμός recommender από το μάθημα. Δεν παρουσιάζονται ως επιβεβαιωμένα ευρήματα.
- Η σύγκριση αφορά ενέργεια + πάγιο ανά 30 ημέρες χωρίς ΦΠΑ. Η μεταβλητή τιμή είναι μόνο snapshot. Δεν υπάρχει εγγύηση μελλοντικού κόστους ή πεδίο υπολογισμένου καθαρού οφέλους αλλαγής.
- Η σύγκριση δύο δηλώνει ρητά ως εύρος όλα τα υπολογίσιμα συμβατά προγράμματα. Έτσι μπορεί να συγκριθεί η προσωπική πρόταση σταθερής τιμής με τη φθηνότερη μεταβλητή εναλλακτική χωρίς αλλαγή προτεραιότητας. Οι προεπιλογές είναι ο πρώτος/οι ισότιμοι της προτεραιότητας και μια διαφορετική πρώτη επιλογή άλλης κατηγορίας, όταν υπάρχει, αλλιώς οι επόμενες συγκρίσιμες εγγραφές. Δεν συγκρίνονται άγνωστες/ασύμβατες χρεώσεις.
- Δεν δημιουργήθηκε repository, δεν προσκλήθηκε collaborator και δεν έγινε deployment ή υποβολή στο e-class σε αυτό το στάδιο.

Ο κώδικας και τα tests αναπτύχθηκαν με βοήθεια AI βάσει των εγγράφων του έργου. Οι αριθμητικές προσδοκίες προέρχονται από τα προηγούμενα χειροκίνητα παραδείγματα· οι παραπάνω έλεγχοι εκτελέστηκαν πραγματικά στο τρέχον στάδιο.

## Ιδέα και κάλυψη της αρχικής εκφώνησης

Το VoltWise βοηθά έναν οικιακό χρήστη να εξετάσει ποιο πρόγραμμα ρεύματος ταιριάζει στις kWh και στους όρους που δέχεται. Η προτεινόμενη διαφοροποίηση είναι ο έλεγχος ισχύος της απόφασης: αρχική σύσταση → αλλαγή παραδοχών → αλλαγή νικητή → ασφαλές όριο → έλεγχος εύρους. Η ανεξάρτητη σύγκριση ή ένα slider δεν τεκμηριώνουν από μόνα τους πρωτοτυπία. Η περιορισμένη έρευνα/επικάλυψη καταγράφεται στο PROJECT_SPEC.md §2· η προσωπική χρησιμότητα και η επάρκεια διαφοροποίησης παραμένουν προς αξιολόγηση.

| Ζητούμενο HW1 | Κάλυψη και πραγματικό όριο |
| --- | --- |
| Πρωτότυπη mobile ιδέα που θα χρησιμοποιούσε ο δημιουργός | Υλοποιημένο mobile mockup ελέγχου απόφασης. Η προσωπική χρήση και η αποδοχή διαφοροποίησης από το μάθημα δεν έχουν επιβεβαιωθεί. Δεν ισχυριζόμαστε μοναδικότητα. |
| Τουλάχιστον recommender system ή predictive model | Knowledge-based recommender με επιλεξιμότητα, πραγματικές χρεώσεις, δύο κατηγορίες, ισοπαλίες και αιτιολόγηση. Δεν υπάρχει ασαφές AI score ή πρόβλεψη μελλοντικών τιμών. |
| Interactive mockup με AI | React + TypeScript + Vite, πραγματικά χειριστήρια/πλοήγηση και τοπικοί επανυπολογισμοί. Το AI χρησιμοποιήθηκε στην προδιαγραφή, ανάπτυξη και ανασκόπηση, χωρίς runtime LLM στο προϊόν. |
| Clickable preview χωρίς απαίτηση backend | Πλήρης τοπικός κύκλος εισαγωγής, προτάσεων, λεπτομερειών, σύγκρισης και Δοκιμής, μαζί με τις δύο προαιρετικές διαδρομές. |
| Κατανόηση από νέο χρήστη | Ορατές μονάδες/labels, διορθώσεις, ξεχωριστή αρχική κατάσταση, επεξηγήσεις και ξεκάθαρα demo δεδομένα. Οι έλεγχοι browser δεν αντικαθιστούν τη μελέτη νέων χρηστών της προδιαγραφής. |
| Εξέλιξη μέσα στο εξάμηνο | Ανεξάρτητοι τύποι, κατάλογος, καθαρές συναρτήσεις και UI επιτρέπουν επέκταση. Πραγματικές τιμές ή σύνθετα μοντέλα απαιτούν τεκμηρίωση/νέους κανόνες. |
| Private GitHub repo, πρόσκληση tedaueb, URL στο e-class | Εκκρεμούν. Δεν έγιναν repository, πρόσκληση ή υποβολή σε αυτή την εργασία ανασκόπησης. |

## Demo παραδοχές και γρήγορη αξιολόγηση

Όλα τα παρακάτω είναι φανταστικά δεδομένα DEMO-1, όχι πραγματικές προσφορές. Κοινή βάση 30 ημερών, ενέργεια + πάγιο, χωρίς ΦΠΑ/άλλους φόρους/ρυθμιζόμενες χρεώσεις. Δεν είναι τελικός λογαριασμός. Ακριβής κανονικοποίηση: q=30Q/d, χωριστά ανά ζώνη, χωρίς ενδιάμεση στρογγυλοποίηση.

| Πρόγραμμα | Πάγιο / 30 ημέρες | Τιμή ενέργειας / kWh |
| --- | --- | --- |
| A1 — Μικρό Πάγιο | 2 € | 0,160 € |
| A2 — Πολλές kWh | 10 € | 0,120 € |
| B1 — Στιγμιότυπο | 4 € | 0,130 €, μεταβλητή τιμή μόνο στο στιγμιότυπο demo |
| C1 — Με Προϋποθέσεις | 3 € | 0,180 € ή 0,100 € μόνο με e-bill YES **και** πάγια εντολή YES |
| D1 — Δύο Ζώνες | 6 € | 0,170 € κανονική, 0,080 € μειωμένη, μόνο με γνωστή διζωνική μέτρηση και κατανομή |

Οι A1/A2/C1/D1 έχουν σταθερή τιμή ανά kWh για 12 μήνες στους φανταστικούς όρους. Αυτό δεν εγγυάται σταθερό τελικό ποσό. Τα τέλη αποχώρησης του καταλόγου είναι ρητά μηδενικά· άγνωστο τέλος χρήστη παραμένει null. Χωρίς ακριβές υπολογίσιμο baseline δεν εμφανίζεται προσωπική χρηματική διαφορά. Ακόμη και με αυτό, η διαφορά αφορά μόνο ενέργεια/πάγιο στο ίδιο σενάριο, χωρίς καθαρό όφελος αλλαγής.

Δοκίμασε για έλεγχο:

1. 900 kWh / 90 ημέρες, μονή μέτρηση, προτεραιότητα σταθερής τιμής, χωρίς εκπτώσεις: A2 46 € έναντι A1 50 €. Στη Δοκιμή 150 kWh: A1 26 € έναντι A2 28 €. Τομή στις 200, αλλά εκεί B1 30 € είναι χαμηλότερο από τα δύο.
2. 300 kWh / 30 ημέρες, κόστος, e-bill και πάγια εντολή YES: μία κάρτα C1 33 € για όλους τους σχετικούς ρόλους. Πάγια εντολή NO/UNKNOWN: C1 57 €, B1 43 € πρώτο. Η έκπτωση δεν αφαιρείται δεύτερη φορά.
3. Έτοιμο δείγμα 360+240 kWh / 60 ημέρες: επιβεβαίωση → 180+120=300 kWh/30 ημέρες, D1 46,20 €. Με ακριβές σημερινό A1: 50 € σήμερα, B1 43 €, διαφορά χρέωσης 7 € και τέλος χωριστά. Η ίδια ροή ολοκληρώνεται και χωρίς δείγμα ή σημερινό πρόγραμμα.

Οι αριθμοί ελέγχονται στα VERIFIED_EXAMPLES.md και στα tests. Η συνεδρία καθαρίζει στην ανανέωση. Η εσωτερική πλοήγηση χρησιμοποιεί τα κουμπιά του mockup, χωρίς URL/history router. Δεν υπάρχουν πραγματικό PDF/OCR, API παρόχων, εκπαίδευση ML, πληρωμές, σύναψη σύμβασης ή μόνιμη αποθήκευση. Οι έλεγχοι έγιναν σε Chrome/Windows με viewports, όχι σε πραγματικά iOS/Android ή όλους τους browsers.
